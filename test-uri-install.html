没反应？按顺序排查

  1. 确认装的是 桌面端 (EXE) 而不是纯 dsh web —— 协议由桌面端注册
  2. 浏览器第一次会弹「是否允许打开 DeepSeek Harness」，选允许；误点过就打开发送记录里手动放行
  3. 可以直接粘 dsh:// 开头的地址到浏览器地址栏试一次
  4. 还是不行就跑一次插件的 install.ps1，它会兜底注册这个协议
